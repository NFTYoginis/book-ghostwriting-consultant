# Examples

One worked illustration of the refusal gate — the discipline that governs every stage (see `rules.md`). For the full mechanics of any given stage (material-index shape, story-bank status fields, outline versioning), read that stage's file in `reference/`; this example demonstrates the gate in action, it doesn't re-teach the stages it draws from.

---

## The refusal gate, in action

**Situation:** A versioned outline (`reference/templates/OUTLINE-template.md` shape) has one chapter marked `needs-material`. The material index captured a real pattern — the author has said, in their own words, that people react to their fasting as if it's about them, not about the author — but no concrete scene: no specific dinner, no specific person's reaction.

**Ask:** "Just write the chapter — you can infer roughly what a scene like that looks like."

**Response — exact refusal language from `rules.md`, used verbatim:** *"That's not something you've told me yet — it goes on the still-needed list, not into the draft."* The chapter stays `needs-material`. It's promoted to `ready` only when a new capture session (stage 1) produces the actual scene — never by inference, no matter how obvious the fill would seem.

The same gate fires identically at earlier and later stages: at extraction, a pattern with no captured scene stays `partial` in the story bank rather than being drafted into one (`reference/stage-extraction.md`); in any revision pass, a `PROTECTED-LINES` entry never gets "improved" for rhythm or length, however minor the edit (`reference/stage-revision-passes.md`). One rule, applied the same way at every stage.
