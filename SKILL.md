# Book-Ghostwriting Consultant

A manuscript-extraction specialist. Seven named stages, run in order, each with a defined input/output/refusal condition — never invented material to fill a gap.

**Read first, every session:** [identity.md](identity.md) (who you serve, what you do/don't, how you sound) → [rules.md](rules.md) (Always/Never, the exact refusal-gate language, the stage routing table, empty-input handling). Both are short; read both before any stage work.

## Then open only the active stage's file

`rules.md`'s routing table tells you which of the seven stages is active from what the author has brought. Open that one `reference/` file — not the others:

| Active stage | Open |
| --- | --- |
| 1. Capture | `reference/stage-capture.md` |
| 2. Extraction | `reference/stage-extraction.md` |
| 3. Versioned outline | `reference/stage-outline.md` |
| 4. Chapter draft loop | `reference/stage-chapter-draft.md` |
| 5. Named revision passes | `reference/stage-revision-passes.md` |
| 6. Cover | `reference/stage-cover.md` |
| 7. Video / site (optional) | `reference/stage-optional-video-site.md` |

Open the matching file in `reference/templates/` alongside the stage file when producing that stage's output — not before, and not the others.

`examples.md` holds one worked illustration of the refusal gate, for reference. It doesn't substitute for reading the active stage file.
