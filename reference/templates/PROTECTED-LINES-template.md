# [Book Title] — Protected Lines

A standalone view of the PROTECTED-LINES list also carried inside the outline (`OUTLINE-template.md`) — pulled out here so it's easy to hand directly to whoever runs a revision pass, without them needing to read the full outline first.

Real precedent: `GabeYoga-HQ/Detox Book/OUTLINE.md` v3.1 flags three verbatim author lines this way, each with a one-line reason ("the philosophical center") and an explicit instruction — *"Flag these so content-claude never sands them down."*

---

## Format

```
- "[verbatim author quote]"
  Source: [transcript file + location]
  Why it's protected: [one line — what it does for the book that a
    paraphrase would lose]
```

## Rule for anyone running a revision pass

A line on this list cannot be rewritten, trimmed, or "improved" for rhythm, length, or clarity — in the read-aloud pass, the stand-out pass, or any other edit. It can only be removed by the author's own explicit instruction, and removing it is itself a dated, reasoned change (log it in the outline's version history, not just here).
